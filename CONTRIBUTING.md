# Contributing to Aviometrics repositories

This applies to every public Aviometrics repository that doesn't have its own `CONTRIBUTING.md`.

- **Questions, bugs and mismatches** between a device and its specification: open an issue on that repository.
  Include what you did, what you expected and what happened, plus a short capture of the data if one is involved.
- **Pull requests** are welcome for code, tests and documentation. Keep changes focused, add a test where it makes
  sense, and make sure the existing tests pass.
- **Changes to a device protocol** start as an issue, because they need firmware changes on our side.
- **Security problems** never go in public issues: see [SECURITY.md](SECURITY.md).

By contributing, you agree your contribution is licensed under the licence of the file you change.
